# Support

Groundwork is a preview-stage, solo-maintained project. There is no guaranteed support response time.

Use GitHub issues for reproducible bugs, documentation corrections, and scoped proposals. Include the version or commit, operating system, Bun version, harness version, command run, JSON input, expected behavior, actual behavior, and relevant logs with secrets and private project data removed.

Questions that depend on private repositories, account setup, unrelated consulting, custom harness forks, or private policy rules may be closed or redirected.
